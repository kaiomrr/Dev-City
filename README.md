## 📌 About the Project

*Dev.City* is an educational digital game developed as a academic project for the *Socioemotional Education* course in the *Software Engineering* major. 

The main objective of the game is to connect technical knowledge in Software Engineering with the five core competencies of the *CASEL framework*:
1. *Self-awareness*
2. *Self-management*
3. *Social awareness*
4. *Relationship skills*
5. *Responsible decision-making*

In *Dev.City*, the player takes on the role of a Tech Lead navigating a pixel-art urban environment in a vehicle. To progress through the city, the player must interact with various buildings and respond to 12 situational scenarios related to project management and team leadership.

---

## 🎮 Game Features

- *Interactive City Map:* Drive around an urban environment designed in pixel art.
- *12 Situational Scenarios:* Tackle real-world software management challenges.
- *3 Difficulty Levels:* Dev Junior, Dev Mid-Level, and Dev Senior.
- *Visual Vehicle Damage System:* Incorrect decisions degrade the vehicle (gray smoke, black smoke, and engine explosion).
- *Radar Chart Performance Summary:* End-of-game visual representation evaluating your socioemotional skills performance based on CASEL competencies.
